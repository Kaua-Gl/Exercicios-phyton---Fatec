# 🐍 Exercícios de Python

Bem-vindo ao meu repositório de exercícios de **Python**!

Este repositório reúne atividades práticas desenvolvidas durante meus estudos de programação, com o objetivo de aprimorar minha lógica, aprender os fundamentos da linguagem Python e desenvolver habilidades na resolução de problemas.

## 📚 Conteúdos estudados

- Variáveis e tipos de dados
- Operadores aritméticos, lógicos e relacionais
- Entrada e saída de dados (`input()` e `print()`)
- Estruturas condicionais (`if`, `elif` e `else`)
- Condicionais aninhadas
- Estruturas de repetição (`while` e `for`)
- Utilização da função `range()`
- Contadores e acumuladores
- Resolução de problemas com lógica de programação

## 🛠️ Tecnologias utilizadas

- **Python 3** — linguagem de programação.
- **Google Colab** — ambiente alternativo para executar notebooks.
- **GitHub** — armazenamento e organização dos códigos.

## 🎯 Objetivo

Meu principal objetivo com este repositório é registrar minha evolução no aprendizado de Python, colocando em prática os conceitos estudados e aprimorando gradualmente minhas habilidades de programação.

O repositório será atualizado conforme novos conteúdos e exercícios forem desenvolvidos.
